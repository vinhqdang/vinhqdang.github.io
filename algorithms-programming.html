Course

Algorithms and Programming Concepts

British University Vietnam · Year 1

A first course in thinking like a computer scientist: how to find, order and organise data, how to measure whether a program is fast, and how to solve problems that are too big to try every possibility. Each topic has one slide deck, and every code example in the slides is a real Python program. The code was run with Python 3.14 and the outputs shown on the slides are the real outputs.

Run any example with python3.14 searching.py (or the file name of the topic).
