Network Protocols

Computers are physically linked by cables, radio or light, yet applications behave as if they talk to each other directly. Protocols make that possible. Send a message down the stack, race packets across a network that breaks, and follow a web request from URL to page.

This page supports British University Vietnam students in the module Introduction to Computing Science (2024–2027 and onwards). It accompanies the Week 8 “Networks” lecture and continues from Networks and the Internet.

1 · Where do protocols fit in?

The protocol stack: a virtual link on top of a physical one

Only the bottom layer is physically connected. Every layer above talks to its partner layer on the other computer (the dashed “virtual links”) by handing its message to the layer below, which wraps it in a header. The Internet’s base protocol set is IP at the bottom with TCP on top. Higher-level protocols (HTTP, FTP, SMTP) sit on top of TCP.

The packet right now

IP: just deliver it

The Internet Protocol is only tasked with sending packets from one node to another. It does not handle lost, damaged or out-of-order packets.

TCP: make it reliable

The Transmission Control Protocol cares about data integrity. It splits the data into packets, adds a header with the order of reassembly and an error-checking value, and rebuilds the data at the destination. The TCP segment travels as the payload of an IP packet.

2 · How does data cross the network?

Packet switching vs circuit switching

Circuit switching reserves one dedicated path from end to end before any data moves (the old telephone network). Packet switching, invented to replace it, chops the message into packets that each find their own way. Send the same message both ways, then cut links and add loss.

    Packet switching: advantages

    Much more efficient use of physical links (nobody owns a line while it is idle). More robust: more lines of communication, a lost connection only loses some of the data, and it is easier and faster to fix.

    Packet switching: disadvantages

    Lost packets (tiny fluctuations in power, conflicting Wi-Fi signals) and wrong order (packets on different routes arrive in different orders). The right protocol, TCP, fixes both.

    IP addresses: IPv4 vs IPv6

    An IPv4 packet header carries a 4-byte source address and a 4-byte destination address, giving 232 (about 4 billion) addresses for roughly 7.8 billion people. IPv6 uses 16-byte addresses.

    4 · What do we use it for?

    HTTP: the protocol of the web

    The World Wide Web is based on the Hypertext Transfer Protocol: a simple client–server protocol. The client is your browser; the server is the web server. Every document is addressed by a Uniform Resource Locator (URL).
